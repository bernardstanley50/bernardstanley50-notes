# bernardstanley50-notes

Compilers · CUDA · GraphQL

处理日常小任务的工具

## 用法

```bash
cat data.txt | cargo run
```

```

---
2 unique / 4 lines
```

```bash
git clone https://github.com/USER/bernardstanley50-notes.git
cd bernardstanley50-notes
cargo build --release
```
